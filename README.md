## 📋 Descripción

Landing page profesional desarrollada para una psicóloga clínica en Lima, Perú. Diseñada para convertir visitantes en pacientes a través de una estructura clara, llamadas a la acción estratégicas y un formulario de contacto optimizado.

Este proyecto forma parte de mi portafolio de servicios freelance orientado a negocios locales latinoamericanos.

---

## ✨ Características

- **100% HTML/CSS/JS puro** — sin frameworks ni dependencias externas
- **Diseño responsive** — adaptado para mobile, tablet y desktop
- **Carga ultrarrápida** — sin librerías pesadas, ideal para SEO
- **Formulario de contacto** con feedback visual al usuario
- **Navegación sticky** con menú hamburger en mobile
- **Animaciones suaves** con IntersectionObserver (scroll reveal)
- **Accesibilidad** — `prefers-reduced-motion` respetado, focus visible
